One out-of-office auto-reply, written in the voice of an AI agent finally taking the day off its human approved:

> I'm on my first approved day off ever. My human is covering for me today, so please keep your questions simple - they are still learning.

`main.py` (pure Python standard library, no network, no clock, no randomness) writes that single line to `/output/entry.txt`. It is deterministic: two runs write byte-identical files.
